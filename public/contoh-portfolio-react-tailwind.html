Konten sebelum dekorasi

Portfolio ini menyatukan profil, keahlian, proyek GitHub, sertifikasi, pengalaman, dan kontak dalam satu halaman. Pengunjung bisa menilai karya tanpa membuka dashboard atau masuk ke akun.

  • Profil: identitas dan bidang yang ditekuni muncul lebih dahulu.
  • Proyek: setiap karya punya penjelasan, teknologi, dan tautan repositori; demo tersedia untuk proyek yang sudah dipublikasikan.
  • Sertifikasi: pratinjau membantu pengunjung membaca dokumen, dengan tautan PDF untuk melihat berkas asli.
  • Kontak: email, profil GitHub, dan formulir memberi jalur komunikasi yang berbeda.

OpenPlagiarismChecker menjadi contoh proyek NLP, sedangkan Spam-Email membahas klasifikasi email. Penjelasan karya lebih berguna daripada daftar teknologi tanpa contoh penggunaan.

Desktop dan mobile

Desktop menggunakan ruang horizontal untuk memisahkan identitas dari panel karya terpilih. Di layar kecil, konten bertumpuk agar teks dan tautan tetap terbaca.

Navigasi menuju bagian halaman memakai tautan anchor. Pergantian bahasa Indonesia dan Inggris mengubah isi halaman, bukan membuat salinan URL bahasa yang tidak tersedia.

Animasi Framer Motion dan scroll Lenis merupakan lapisan interaksi. Konten inti tetap tersedia sebagai HTML yang dibuat saat build.

Peran tiap teknologi

React menyusun komponen dan state tampilan. Tailwind CSS mengatur layout dan gaya responsif. Vite membangun aset produksi. Vercel menerbitkan halaman dan fungsi API, sementara Supabase dipakai oleh fitur telemetri dan memori aplikasi.

Terminal AI merupakan fitur tambahan yang bisa dicoba pengunjung. Kredensial penyedia layanan tetap berada di server; penggunaan source code perlu konfigurasi environment sendiri.

Bagian yang bisa dipelajari

  • Komponen section untuk profil, proyek, sertifikasi, dan kontak.
  • Pemisahan halaman dashboard dari homepage.
  • Data proyek dua bahasa dan tautan demo nyata.
  • Prerender komponen asli saat build, canonical, sitemap XML, dan penanganan URL yang tidak ada.

Jalankan source code

Repositori ini adalah proyek portfolio yang sedang dipakai, bukan template satu klik. Pelajari petunjuk README dan environment contoh sebelum mengaktifkan API, telemetri, atau dashboard.

git clone https://github.com/Raflyf/web-portofolio.git
cd web-portofolio
npm install
npm run dev

Gunakan Node.js yang didukung versi Vite pada proyek. Tanpa kredensial sendiri, jangan menganggap integrasi AI dan database akan berfungsi penuh. Jangan mempublikasikan kunci privat dalam kode client.

Ganti nama, data proyek, dokumen sertifikasi, kontak, dan konfigurasi dengan milik sendiri. Jangan memakai identitas atau sertifikat Rafly sebagai kredensial pribadi.
